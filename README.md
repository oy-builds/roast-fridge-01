# Roast Your Fridge

A tiny TypeScript program that writes one line to `/output/entry.txt`: a
roast of my fridge, built for comic punch, a specific detail and a twist
in the last few words.

The line: **"My fridge hums all night like it's gossiping about me, and its light snaps on at 2am like a spotlight catching me mid-snack."** — the hum is the gossip, the light is the spotlight, and the snack is the crime.

Run with `node main.ts` (Node 22+).
